on 2026-09-09, because the surface is unchanged and the semantics are not:

  - The method and function names below, and their arity, are the same at v2.0.2.
  - Writing to an exported constant raises `read only`. It used to succeed, and
    before v2.0.2 the change was visible to every mod on the server.
  - A bad argument raises `format error`. The from* constructors used to return
    nil, so a wrong line failed somewhere else entirely.
  - The circle/disk/sphere/ball samplers no longer loop for ever on the
    exact-surface case (r1 == r2). At v1.5 that hung the server.
